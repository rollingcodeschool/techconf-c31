# Proyecto TechConf

**Sitio web responsivo** para un evento de tecnología, diseñado y maquetado desde cero como práctica de desarrollo frontend estático. El objetivo principal fue construir una interfaz moderna, accesible y totalmente adaptable a cualquier dispositivo móvil o de escritorio.

## 💻 Demo del proyecto

Puedes explorar el sitio desplegado en producción aquí: [techconf-c30](https://techconf-c30.netlify.app/)

## 🛠️ Herramientas utilizadas

- HTML5
- CSS3
- [Bootstrap v5.3](https://getbootstrap.com/docs/5.3/getting-started/introduction/)

## 📖 Pasos para probar el proyecto

En una terminal realiza los siguientes pasos para clonar y probar el proyecto:

1. Clonar el repositorio: ```git clone https://github.com/rollingcodeschool/techconf-c31.git```
2. Ingresa a tu editor preferido, por ej: vscode y ejecute el index.html
